# Processed Data

This directory contains final dataset artifacts generated by the pipeline:

- `rnmod_master.parquet`
- `rnmod_master.tsv.gz`
- `rnmod_sequences.faa`
- `rnmod_label_matrix.parquet`
- `source_manifest.tsv`
- `rnmod_dataset_card.md`

These files are ignored by Git. Rebuild them with:

```bash
scripts/01_run_pipeline.sh
```
